# UNILUME-AI

Cross-border e-commerce operational-decision platform, built ontology-first on a
Palantir-style architecture (MMDP six layers + GitOps delivery).

The org repository (`.github`) holds **org-wide defaults**: reusable CI workflows (机器门 /
machine gate), the policy-bot approval policy (人评门 / human gate), and shared issue/PR
templates. Governance and the planning ladder are defined in
[`scrum`](https://github.com/UNILUME-AI/scrum) and [`harness`](https://github.com/UNILUME-AI/harness).
